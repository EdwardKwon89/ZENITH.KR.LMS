## 목표

- 청구서 조회는 **실제 청구 대상 조직(`billed_org_id`)** 기준으로 필터링한다.
- 화주는 자기에게 청구된 인보이스만, 대리점은 자기 청구·발행 범위만 조회한다.

## 결함 성격

- 조회 필터가 청구 주체가 아닌 원본 화주 기준이어서, 표시 범위가 청구 단계와 어긋날 수 있음.
- 노출되는 정보 종류·재현 형태·경로는 공개 문서에 기재하지 않는다(비공개 보고).

## 조치 결과 (TASK-B-249)

- 화주 계열 조회 필터를 `billed_org_id` 기준으로 변경 — **적용됨**.
- RLS 정책 재설계는 이 Task 범위 밖(별도 검토).

## 검증
