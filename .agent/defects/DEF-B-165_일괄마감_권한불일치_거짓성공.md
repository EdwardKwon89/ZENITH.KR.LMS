## 목표

- 일괄 마감의 역할·대상 조건을 **admin 3역할**로 정렬한다.
- 개별 마감 결과가 실제 반영 여부와 일치하도록 한다.

## 현상

- 개별 마감 결과가 실제 DB 반영 여부와 무관하게 성공으로 집계되어, 화면·서버는 완료를 표시하지만 DB 상태는 바뀌지 않는 **거짓 성공**이 발생할 수 있다.

## 영향

- 규칙 1(정산마감 admin 전용)과 충돌한다.
- 감사·화면 표시와 실제 상태가 불일치한다.

## 권장 조치 (별도 Task, 권한 확대 금지)

1. 일괄 마감의 역할 가드를 admin 3역할로 정렬.
2. 화면 버튼 노출 조건을 같은 역할 기준으로 계산.
3. 개별 마감이 실제 갱신 행 수/최종 상태를 반환하도록 정비(DEF-B-166과 함께).
4. 실DB 세션 테스트: 비admin 거부, admin 성공 후 최종 상태 확인, 대상 범위 확인.

## 참고

- 상세한 현재 상태 근거는 공개 문서에 쓰지 않고 비공개로 전달한다.
