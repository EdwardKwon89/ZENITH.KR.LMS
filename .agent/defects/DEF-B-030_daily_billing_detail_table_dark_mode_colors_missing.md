# DEF-B-030: 화주별 일별 청구 "상세" 펼침 테이블의 색상이 요약 테이블과 불일치(다크모드 대응 누락)

| 항목 | 내용 |
|:-----|:------|
| **발견 경위** | JSJung 요청으로 `/finance/daily-billing` 상세 리스트 색상 표출을 Jaison이 직접 코드 확인 |
| **긴급도** | Low |
| **영향 범위** | `src/components/finance/ShipperDailyBillingClient.tsx` (상세 펼침 테이블, 214-219행) |

## 현상

`/finance/daily-billing`에서 그룹 "상세"를 펼치면 나오는 개별 오더 목록 테이블의 기본운임·유류할증·급증수수료·기타부과금·사후조정·합계 컬럼 색상이, 바로 위 요약 테이블의 동일 항목 색상과 어긋나 보임.

## 근본 원인

상세 테이블(214-219행)과 요약 테이블(69-113행)의 동일 항목 컬럼 색상 클래스 비교:

| 항목 | 요약 테이블 (정상) | 상세 테이블 (문제) |
|:-----|:------|:------|
| 기본운임 | `text-slate-700 dark:text-slate-300` | 색상 클래스 없음 |
| 유류할증 | `text-slate-700 dark:text-slate-300` | 색상 클래스 없음 |
| 급증수수료 | `text-amber-600 dark:text-amber-400` | `text-amber-600` (dark 변형 누락) |
| 기타부과금 | `text-purple-600 dark:text-purple-400` | `text-purple-600` (dark 변형 누락) |
| 사후조정 | `text-blue-600 dark:text-blue-400` | `text-blue-600` (dark 변형 누락) |
| 합계(KRW) | `text-amber-600 dark:text-amber-400` | `text-amber-600` (dark 변형 누락) |

상세 테이블 쪽만 `dark:` 변형이 전부 빠져 있고, 기본운임/유류할증 두 항목은 색상 클래스 자체가 없음. 다크모드에서는 요약 행(밝은 톤)과 바로 아래 펼쳐지는 상세 행(라이트모드용 진한 톤이 어두운 배경 위에 그대로 남음)의 대비가 달라 탁하게 보이고, 라이트모드에서도 기본운임/유류할증 두 열은 색상 미지정으로 다른 열과 톤이 어긋나 보임.

## 발생 시점

`git blame` 확인 결과 이 상세 테이블 자체가 `1ebfef3e`(TASK-237, 2026-07-28)에서 요약 화면과 함께 신규 작성되면서 다크모드 클래스만 누락된 채 들어감 — PR#962/#965(계산 로직 수정)와는 무관.

## 권장 조치

- 급증수수료/기타부과금/사후조정/합계: 각각 `dark:text-amber-400`/`dark:text-purple-400`/`dark:text-blue-400`/`dark:text-amber-400` 추가
