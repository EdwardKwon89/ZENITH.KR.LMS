## 현상 (a) — 0행 갱신을 성공으로 처리

- 마감 처리에서 갱신 결과의 **행 수를 검사하지 않고** 오류만 확인한다.
- 권한·정책 등으로 0행이어도 마감 이력이 기록되어, 성공 응답과 실제 최종 상태가 불일치할 수 있다.

## 현상 (b) — 부분 성공 경로

- 마감 권한/정책에 따라 마감 호출이 실패할 수 있다.
- 원가 저장 경로가 마감 실패를 경고만 남기고 **원가만 저장된 부분 성공 상태**로 반환할 수 있다.

## 영향

- 감사 추적에 실제로 마감되지 않은 이력이 남을 수 있다.
- 화면·서버 성공 표시와 실제 DB 상태가 불일치한다(DEF-B-165와 동일 계열).

## 권장 조치 (별도 Task)

1. 마감 갱신 후 영향 행 수/최종 상태를 확인해 0행이면 실패 반환 + 이력 미기록.
2. 마감 권한/정책 정렬 여부는 JSJung 결정. 결정 전에는 부분 성공을 명시적 실패/부분성공으로 반환.
3. 실DB 세션 테스트: 권한별 마감 시 최종 상태·이력 불변/정상 확인.

## 참고

- 상세한 현재 상태 근거는 공개 문서에 쓰지 않고 비공개로 전달한다.
