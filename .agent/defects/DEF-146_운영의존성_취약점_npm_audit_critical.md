## 3. 영향 범위 (미확인)
- **실제 악용 가능성은 분석하지 않았다.** `npm audit`은 권고(advisory)의 영향 버전 범위만 보며, 해당 취약 기능을 이 프로젝트가 호출하는지(도달 가능성)·우리 배포 환경(Vercel)에서 성립하는지는 보지 않는다.
- `xlsx`는 대량 등록 엑셀 업로드에 쓰이는 것으로 보이나 사용 위치·입력 신뢰 경계는 확인하지 않았다.
- `next`는 프레임워크 본체라 업그레이드 시 호환성 검증 범위가 넓다.

## 4. 원인 (확인된 것 / 추정)
- 확인: 의존성 취약점을 보는 자동 점검과 알림이 없어 누적을 알 방법이 없었다.
- 추정(미검증): 기능 개발 우선 운영으로 업그레이드가 후순위가 되었을 가능성.
