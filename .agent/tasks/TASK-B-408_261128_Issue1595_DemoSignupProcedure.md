| 경로 | 발송 함수 | 외부 발송 | 실측 결과 | 비고 |
|:--|:--|:--:|:--|:--|
| **가입** (제출 직후) | 가입 안내 메일 (`sendSignupWelcomeEmail`) | **예** (Resend API 호출) | 발송 요청 1건 → API 응답 **실패**(발신 도메인 미검증) | 가입 액션 내부에서 **비밀번호를 본문에 포함**해 발송하는 구조 |
| **인증(확인) 메일** | supabase auth | **아니오** (0건) | Inbucket 0건 실측 | `enable_confirmations=false` — 발송 자체가 없음 |
| **승인** | — | **아니오** (0건) | 승인 RPC에 메일 코드 없음(코드·DB 함수 grep 0건) | 자동 안내 메일 없음 |
| **대리점 화주 등록** | 임시 로그인 정보 안내 (`sendShipperWelcomeEmail`) | **예** (Resend API 호출) | 발송 요청 1건 → API 응답 **실패**(동일 사유) | 임시 비밀번호를 본문에 포함 |
