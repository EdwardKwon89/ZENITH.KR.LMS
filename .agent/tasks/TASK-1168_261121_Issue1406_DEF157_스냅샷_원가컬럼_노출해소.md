## 3. 조치 방안 (`DEF-153` / `TASK-1166` 안전 뷰 패턴 재사용)

`DEF-153` (`20261118100000`, `20261118100100`)과 동일하게 **2단계(Additive Safe View → 앱 코드 전환 후 Base Table RLS 축소)** 로 진행합니다.

1. **1/2 마이그레이션 (`zen_order_rate_snapshots_safe` 뷰 생성 — Additive)**
   - `DEFINER` 뷰(`public.zen_order_rate_snapshots_safe`) 생성 (`postgres` 소유).
   - `carrier_cost_amount`, `platform_fee_amount` 제외.
   - `metadata`는 화주/실측 계산에 필요한 `platform` 키만 제한 투영(`CASE WHEN s.metadata ? 'platform' THEN jsonb_build_object('platform', s.metadata->'platform') ELSE '{}'::jsonb END`)하거나, 불필요 시 제외.
   - 뷰 `WHERE` 절로 기존 조회 범위(`ADMIN`/`ZENITH_SUPER_ADMIN`/`MANAGER` 또는 해당 오더의 화주 조직원·배정 대리점) 유지.
   - `REVOKE ALL FROM PUBLIC, anon, authenticated; GRANT SELECT TO authenticated;`
2. **앱 코드 전환 (`src/` — Team B 소유 파일 포함, Aiden `[설계 확정]` 대기)**
   - **주의점**: `orders.ts`(L1151) 및 `rate-snapshot-refresh.ts`(L158)는 화주/대리점 세션에서 `UPDATE ... WHERE order_id = ...`를 수행하므로, base table `SELECT` 정책 제거 시 `UPDATE`가 영향받습니다. 따라서 화주/대리점 경로의 `SELECT`는 `zen_order_rate_snapshots_safe`로 전환하고, `INSERT`/`UPDATE`는 서버 권한 검증 후 `createAdminClient()`(`service_role`) 또는 `SECURITY DEFINER` RPC로 전환해야 합니다.
   - 변경 필요 후보 `src/` 파일 목록:
     - `src/app/actions/operations/tisa.ts` (Team A)
     - `src/app/actions/operations/orders.ts` (Team B)
     - `src/lib/orders/rate-snapshot-refresh.ts` (Team B)
     - `src/app/actions/finance/order-revenue-cost.ts` (Team A/B — 역할 가드 확인 시)
3. **2/2 마이그레이션 (Base Table RLS 축소)**
   - 앱 코드 전환 완료 후 `order_members_can_view_rate_snapshots`, `Agency can view shipper order rate snapshots` 정책 제거 및 관리자(`ADMIN`, `ZENITH_SUPER_ADMIN`, `MANAGER`) 전용 `SELECT` 정책으로 대체.

## 4. 롤백 SQL

```sql
-- 2/2 마이그레이션 롤백 (기존 SELECT RLS 복구)
DROP POLICY IF EXISTS "Admins can view order rate snapshots" ON public.zen_order_rate_snapshots;

CREATE POLICY "order_members_can_view_rate_snapshots"
ON public.zen_order_rate_snapshots
FOR SELECT TO authenticated
USING (
  EXISTS (
    SELECT 1 FROM public.zen_orders o
    WHERE o.id = zen_order_rate_snapshots.order_id
      AND public.is_org_member(auth.uid(), o.shipper_id)
  )
);

CREATE POLICY "Agency can view shipper order rate snapshots"
ON public.zen_order_rate_snapshots
FOR SELECT TO authenticated
USING (
  EXISTS (
    SELECT 1 FROM public.zen_orders
    WHERE zen_orders.id = zen_order_rate_snapshots.order_id
      AND zen_orders.agency_org_id = (
        SELECT zen_profiles.org_id FROM public.zen_profiles WHERE zen_profiles.id = auth.uid()
      )
  )
);

-- 1/2 마이그레이션 롤백 (안전 뷰 제거)
REVOKE ALL ON public.zen_order_rate_snapshots_safe FROM authenticated;
DROP VIEW IF EXISTS public.zen_order_rate_snapshots_safe;
NOTIFY pgrst, 'reload schema';
```
