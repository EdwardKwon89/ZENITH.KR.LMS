## 회의 주요내용

### 원가
- SNTL은 홍콩회사로부터 원가를 받고 있음(홍콩$ 기준)
- 최근 환율 변동으로 원가 조정 이슈 발생
- **요청사항**:
  - 현재 원가관리를 KRW으로 관리하는데, 홍콩$로 관리하면 환율 적용하여 비교적 정확한 이윤계산 가능
  - 원가관리 기준 결정 요청(홍콩회사와 협의 후 연락 주기로 함)
  - 그 이전까지 KRW로 관리

### 급증수수료
- 현재 등록된 급증수수료 자료 확인 필요 — 한국기준 도착국 급증수수료는 화폐단위가 KRW임

### 입고시 프로세스
- 화주가 오더 생성 시 등록한 부피중량/중량 정보는 입고 시 실측한 정보로 대체됨 — 입고 시 부피중량/중량 수정 가능해야 함

### 물류프로세스
- 여러 건 선택하여 일괄 처리 가능해야 함

### 정산
- 오더 등록~출고확정 전까지 예상운임표 생성(기본운임·유류할증·급증수수료만 포함)
- 배송완료 후 UPS 청구서 수령 → 부가요금 수기 등록 및 최종운임 확정
- 최종운임 기반 청구서 생성
- 화주/사 별 일/주/월 청구(청구는 최종운임 확정일 기준)

### 오더관리
- 일괄등록기능 필요 — 엑셀 업로드(양식 생성 및 배포 필요)

### 알람기능
- 오더상태변경 및 청구서 발행 등 화주/대리점 대상 알람 기능(email)
