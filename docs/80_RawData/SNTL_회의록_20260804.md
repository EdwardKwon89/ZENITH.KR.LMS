## 잔여작업 정리

- UPS 원가, 판매가, 유류할증율, 급증 긴급 수수료 등 최신 자료 반영(현실화)
- UPS 청구서 수신 후, 최종 원가 정보 입력 기능(부피/중량 정보 수정 포함, 환율관리 기능 필요 — UPS원가는 홍콩$로 입력되며, 해당 오더의 출고확정일 기준으로 KRW 변환)
- 오더별 청구서 발행 및 입금 확인 등 관리 기능 보완(현재 Tracking과 통합된 기능을 별도 분리 + 해당 화면에서 집계 기능도 구현 — 즉 하나의 화면에서 관리·집계 통합)
- 창고업무·관리업무 분리
  - 입고: 오더번호/로컬운송장번호 스캔으로 자동 입고처리
  - 출고처리: 오더번호/로컬운송장번호 스캔으로 자동 출고처리, UPS 라벨 출력(UPS운송장, 세관신고서, Invoice)
  - 바코드 리더 및 QR스캐너 연동기능 확인 필요
- 오더 등록화면에서 오더번호 출력 기능 추가(현장 Pick up일 경우)

## 추가 사항

- admin 권한으로 특정 화주의 오더정보 입력할 수 있는 기능 제공 필요
  - **사유**: 초기 시스템 안착 전까지 고객은 유선으로 UPS배송 요청 가능(현재 처리 방식) — 추후 시스템 안착되면 화주가 직접 입력하도록 유도
  - **기능 개요**: admin 권한으로 특정 화주의 오더 정보 입력·저장, 이때 운송비 산정 시 해당 화주에 부여된 할인율이 반영되어야 함(admin 권한의 운송비가 그대로 적용되면 안 됨)
